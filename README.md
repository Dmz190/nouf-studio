# Nouf Sales Message Studio

أداة عمل لإنشاء وتعديل وترجمة رسائل واتساب وإيميلات المبيعات لخدمات الإنترنت والاتصال وتأسيس البنية التحتية التقنية، بصوت **Nouf** ممثلة المبيعات في **Caiperia Internet Services**.

صفحة واحدة `index.html` بدون Backend وبدون أي مفاتيح API. كل شيء يعمل داخل المتصفح.

---

## ⚠️ ملاحظة أمنية مهمة

هذا المستودع **عام (Public)**. يعني:

- كلمة المرور في شاشة الدخول **محلية داخل الملف**، وأي شخص يفتح كود الصفحة يستطيع معرفتها وتجاوز الشاشة.
- الشاشة تمنع الفتح العابر فقط، وليست حماية أمنية.
- لا تضع في الأداة أي بيانات عملاء حساسة أو أسعارًا سرية أو مستندات داخلية.

لو احتجت حماية حقيقية، الحل هو نسخة بـ Backend تتحقق من كلمة المرور من خلال Environment Variable، أو مستودع خاص مع استضافة محمية.

---

## الاستخدام

1. افتح الرابط أو `index.html` مباشرة في المتصفح.
2. أدخل كلمة المرور، ثم اضغط **فتح الأداة**.
3. اكتب أمرًا في **شريط الأوامر الذكي**، أو اختر رسالة جاهزة من المكتبة.

### صيغة الأوامر

```
القناة – اسم العميل – المطلوب
القناة – اسم العميل – المطلوب – الخدمة – السياق
```

أمثلة تعمل كما هي:

```
إيميل – عمر – تعريف بالشركة
واتساب – عمر – تواصل أول مرة
Email – Umer – Company Introduction
WhatsApp – Umer – Follow-Up
واتساب – عمر – الرد على وجود مزود حالي
إيميل – عمر – تعريف بالشركة – تجهيز غرفة السيرفرات – الأستاذ عبدالرحمن اقترح التواصل معه
```

الأداة تقبل `-` أو `–`، وتتحمل الأخطاء الإملائية البسيطة، وتتجاهل المسافات الزائدة. إذا كان الأمر ناقصًا تطلب الجزء الناقص فقط. وتستخرج اسم من رشّح التواصل من السياق تلقائيًا، وتحوّل الاسم العربي إلى صيغته اللاتينية داخل النص الإنجليزي.

## المحتوى

- **21 سيناريو واتساب**: من التواصل الأول، إلى وجود مزود حالي، إلى الخط الاحتياطي، إلى زيارة الموقع، إلى المتابعة الأخيرة بأدب.
- **11 قالب إيميل**: تعريف، ملف تعريفي، عرض خدمات، طلب وتأكيد اجتماع، زيارة موقع، متابعة عرض، تسجيل مورد، متابعة عامة، ومتابعة أخيرة.
- كل رسالة لها: نص إنجليزي، ترجمة عربية، مرحلة (Introduction / Qualification / Meeting / Proposal / Follow-Up)، وأزرار نسخ وحفظ وإرجاع.
- **تسلسل التواصل**: Day 1 واتساب، Day 2 إيميل، Day 4 متابعة واتساب، Day 7 متابعة إيميل، Day 10 متابعة أخيرة.

### قواعد الكتابة

- إنجليزية مهنية بسيطة، واثقة وإنسانية، استشارية وليست ضاغطة.
- هدف الرسالة الأولى فتح الحوار وتحديد مكالمة، لا سرد كل الخدمات.
- لا أسعار، ولا تغطيات، ولا SLA، ولا شهادات، ولا أي وعد غير مؤكد.
- لا تُذكر أي خدمة خارج قائمة الخدمات المعتمدة داخل الأداة، والقائمة قابلة للإضافة والتعديل والحذف.

## المزايا

| ميزة | ملاحظة |
|---|---|
| محرر بعمودين | إنجليزي LTR وعربي RTL، مع عدّاد كلمات وأحرف وتنبيه لطول رسالة الواتساب |
| 10 حقول قابلة للتعديل | اسم العميل، اللقب، شركته، اسمك، شركتك، من رشّح التواصل، الخدمة، نوع المشروع، الوقت المقترح، سياق إضافي |
| تحديث ذكي | تعديل أي حقل يحدّث الاسم أو الخدمة داخل النص دون مسح تعديلاتك اليدوية |
| Subject تلقائي | للإيميلات، مع زر نسخ Subject مع النص |
| بحث وفلاتر | بحث نصي، وفلترة بالقناة والمرحلة والخدمة |
| حفظ محلي | النسخ المعدلة والحقول وآخر الأوامر تُخزَّن في `localStorage` لنفس المتصفح |
| ترجمة | زر Translate to Arabic، وترجمة تلقائية اختيارية بعد التوقف عن الكتابة |
| قائمة خدمات | إضافة وتعديل وحذف، مع إمكانية إرجاع القائمة الأصلية |

## التقنية

- HTML و CSS و JavaScript في ملف واحد، بدون أي مكتبة خارجية.
- الخطوط: عائلة IBM Plex (Sans، Sans Arabic، Mono، Sans Condensed) من Google Fonts، مع بدائل نظامية.
- تصميم Mobile-First، أزرار مناسبة للمس، واجهة RTL مع نصوص إنجليزية LTR.
- ثيم داكن (Dark Navy + Electric Blue + Turquoise) مع ثيم فاتح يتبع إعداد الجهاز.
- التخزين: `localStorage` للتعديلات والخدمات والأوامر، و `sessionStorage` لحالة الدخول.
